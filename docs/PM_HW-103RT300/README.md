## 이상 발생 시

`「×」 판정 → 즉시 공무팀 통보 → 생산 정지 여부 판단 → 조치 → 고장 이력 등재 → 재발 방지 → 필요 시 PM 주기·기준값 개정`

하자보증 기간(12개월) 내 고장은 공급자 A/S로 처리하고, 자체 조치 전 공급자에게 통보한다.
