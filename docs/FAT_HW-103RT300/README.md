# FAT — 자동용기포장기(컵실링기) HW-103RT300

컵실링기 출하 전 공장검사(Factory Acceptance Test) 프로토콜 겸 성적서. 검사 현장에서 그대로 기입하는 양식.

| 파일 | 용도 |
|---|---|
| `FAT_자동용기포장기_컵실링기_HW-103RT300_Rev0.docx` | 인쇄·기입용 (A4 가로, 19p) |
| `FAT_자동용기포장기_컵실링기_HW-103RT300_Rev0.md` | 텍스트 원본 (검토·수정용) |
| `fat_data.js` | 검사 항목 데이터 (단일 원본) |
| `fat_gen.js` / `fat_md.js` | docx / markdown 생성 스크립트 |

## 개요

| 항목 | 내용 |
|---|---|
| 문서번호 | FAT-PKG-2026-001 (Rev.0) |
| 근거문서 | URS-PKG-2026-001 (Rev.0) — `../URS_HW-103RT300/` |
| 검사 항목 | 총 76항목 / 8개 그룹 (A~H) |
| 실물 시험 | 실제 용기(PP 외경 95mm) · 실제 인쇄 리드지 100컵 |
| 실측 기록지 | 7종 (온도 10점, 사이클 3회, 아이마크 20컵, 100컵 집계, 누설, 소음, 결로) |

## 검사 그룹

| 그룹 | 분야 | 항목 수 |
|---|---|---|
| A | 외관 · 사양 · 재질 | 10 |
| B | 안전장치 (조건부 합격 제외) | 11 |
| C | 무부하 운전 | 6 |
| D | 제어 · HMI 기능 | 13 |
| E | 실링 성능 (조건부 합격 제외) | 10 |
| F | 아이마크 정위치 (조건부 합격 제외) | 5 |
| G | 스크랩 · 배출 · 작업성 | 9 |
| H | 부속품 · 옵션 · 제출 문서 | 12 |

전 항목은 URS 요구사항 ID와 추적 연결되어 있고, FAT에서 검증할 수 없는 항목은 부속서 A에서 IQ / OQ / PQ / SAT / DOC 단계로 이관한다.

## 수정 방법

검사 항목은 `fat_data.js` 한 곳만 수정하고 두 스크립트를 재실행한다.

```bash
npm install docx
node fat_gen.js   # docx 생성 (A4 가로)
node fat_md.js    # markdown 생성
```

렌더링 확인:

```bash
soffice --headless --convert-to pdf FAT_*.docx
pdftoppm -jpeg -r 80 FAT_*.pdf page
```
