## 문서 생성 · 수정

모든 문서는 `data.js`(요구사항·검사 항목 데이터) → `gen.js`(docx) / `md.js`(markdown) 구조로,
데이터 한 곳만 수정하면 두 형식이 동시에 갱신된다. 브랜드 양식은 `_lib/sbdoc.js` 공용 모듈을 사용한다.

```bash
npm install docx            # 최초 1회
cd docs/PM_HW-103RT300
node gen.js && node md.js
```

렌더링 확인:

```bash
soffice --headless --convert-to pdf *.docx
pdftoppm -jpeg -r 80 *.pdf page      # 생성된 page-*.jpg 확인
```

> URS · FAT은 공용 라이브러리 도입 이전에 작성되어 각 폴더에 자체 헬퍼를 포함한다.
> 향후 개정 시 `_lib/sbdoc.js` 사용으로 통합할 수 있다.
