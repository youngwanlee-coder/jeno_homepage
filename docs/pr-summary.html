Sweetbalance Idea

버튼 하나로 오늘 점심 고민을 끝내는 룰렛

"오늘 점심 뭐 먹지?"를 대신 정해주는 실제로 작동하는 8칸 룰렛입니다. 브로콜리·토마토·당근·양상추·파프리카·아보카도·고구마·오이 중 하나가 무작위로 뽑히고, 막연한 "몸에 좋아요" 대신 구체적인 영양 수치와 오늘 바로 실천할 수 있는 팁을 보여줍니다.

  • 1"룰렛 돌리기" 버튼 클릭 → 실제 CSS 애니메이션으로 룰렛이 회전
  • 2멈춘 위치를 계산해 정확히 그 채소의 결과 카드를 표시 (예: "고구마 · 식이섬유 3g, 든든한 탄수화물이에요.")
  • 3몇 번 돌렸는지 카운트가 쌓이고, "다시 돌리기"로 반복 가능
  • 4색상은 매뉴얼 규칙("화면당 Secondary 컬러는 1개만")을 지켜 Seed Green 계열로만 구성
