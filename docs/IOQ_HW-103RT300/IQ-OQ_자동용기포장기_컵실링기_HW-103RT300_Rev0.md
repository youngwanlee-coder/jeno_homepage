## 1. 개요
### 1.1 목적
자동용기포장기(컵실링기) HW-103RT300의 현장 설치 상태(IQ)와 운전 기능(OQ)을 확인하여, URS-PKG-2026-001에 규정된 요구사항의 충족 여부를 판정한다. 아울러 OQ 단계에서 실링 온도·시간·압력 등 표준 운전 조건을 확립하여 PQ 및 표준작업절차서(SOP)의 기준값으로 확정한다.

### 1.2 구성 및 실시 순서
- **IQ (설치확인) 41항목** — 반입·설치, 유틸리티 결선, 부속품 인수, 위생·재질, 제출 문서, 표지·등록
- **OQ (운전확인) 53항목** — 안전장치, 기본 운전, 제어·HMI, 실링 조건 확립, 아이마크·트리밍, 배출·컨베이어, 세척·정비성, 작업자 조작
- 실시 순서: 선행 조건 확인 → IQ 실시 및 판정 → (IQ 합격 시) OQ 실시 및 판정 → 표준 운전 조건 확정 → PQ 진행
- IQ 부적합 항목이 있으면 OQ를 착수하지 않는다. 설치가 완결되지 않은 상태의 운전 데이터는 유효하지 않다.

### 1.3 판정 기준
| 구분 | 기준 |
|---|---|
| 항목별 판정 | 합격 기준 충족 시 「적합」, 미충족 시 「부적합」. 해당 없음은 「N/A」 |
| **IQ 합격** | 41항목 전 항목 적합 — 단, 제출 문서(I-5) 미비는 시정 기한 명기 후 조건부 합격 가능 |
| **OQ 합격** | 53항목 전 항목 적합 및 표준 운전 조건 확정 완료 |
| **OQ 불합격** | O-1 안전장치 1건 이상 부적합, 또는 O-4 실링 조건 확립 실패, 또는 O-5 정위치 정밀도 미달 |
| 조건부 합격 제외 | O-1(안전장치) · O-4(실링 조건) · O-5(아이마크 정위치) |
