## 실시 순서

`선행 조건 확인 → IQ 실시·판정 → (IQ 합격 시) OQ 실시·판정 → 표준 운전 조건 확정 → PQ 진행`

IQ 부적합이 있으면 OQ를 착수하지 않는다. O-1(안전장치) · O-4(실링 조건) · O-5(아이마크 정위치)는 조건부 합격 대상에서 제외한다.
