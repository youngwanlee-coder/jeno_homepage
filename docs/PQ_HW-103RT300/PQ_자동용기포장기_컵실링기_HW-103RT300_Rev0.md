## 1. 개요
### 1.1 목적
IQ · OQ에서 확립한 표준 운전 조건으로 실제 생산 조건에서 3배치를 연속 운전하여, 자동용기포장기(컵실링기) HW-103RT300이 URS-PKG-2026-001의 성능 요구사항을 양산 조건에서 지속적으로 충족하는지 확인한다. 본 문서의 합격이 최종 인수(검수조서 서명)의 전제 조건이다.

### 1.2 PQ가 확인하는 것 — FAT · OQ와의 차이
- **FAT · OQ는 「할 수 있는가」** — 최적 조건에서 100컵, 20컵 표본으로 기능과 성능의 가능성을 확인
- **PQ는 「계속 되는가」** — 실제 원료·실제 작업자·실제 교대 조건에서 배치당 500컵 이상, 3배치 반복으로 재현성을 확인
- 따라서 PQ에서는 조건을 조정하지 않는다. 조건 조정이 필요하면 OQ로 되돌아가 표준 조건을 재확립한 후 PQ를 다시 시작한다.

### 1.3 판정 기준
| 구분 | 기준 |
|---|---|
| 배치별 판정 | 2장 합격 기준(Q-01 ~ Q-14) 중 해당 항목 전량 충족 시 「합격」 |
| **PQ 합격** | 3배치 모두 배치 판정 합격 + 3배치 합계 기준 충족 + 배치간 재현성(Q-11) 충족 |
| **PQ 불합격** | 1배치라도 불합격, 또는 3배치 합계 불량률 0.5% 초과, 또는 배치간 불량률 편차 0.3%p 초과 |
| 재시험 | 불합격 원인 규명·시정 후 **3배치를 처음부터 다시 실시**. 불합격 배치만 재실시하는 방식은 인정하지 않는다. |
| 조건 변경 시 | 표준 운전 조건을 변경하면 변경 후 조건으로 3배치를 전부 재실시 |
