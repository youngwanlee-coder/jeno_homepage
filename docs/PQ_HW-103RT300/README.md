# PQ — 자동용기포장기(컵실링기) HW-103RT300

성능확인(PQ) 프로토콜 겸 3배치 성능확인서. A4 가로 22페이지.

| 파일 | 용도 |
|---|---|
| `PQ_자동용기포장기_컵실링기_HW-103RT300_Rev0.docx` | 인쇄·기입용 |
| `PQ_자동용기포장기_컵실링기_HW-103RT300_Rev0.md` | 텍스트 원본 |
| `data.js` | 합격 기준 · 기록 항목 데이터 |
| `gen.js` / `md.js` | docx / markdown 생성 스크립트 |

## 개요

| 항목 | 내용 |
|---|---|
| 문서번호 | PQ-PKG-2026-001 (Rev.0) |
| 근거문서 | URS-PKG-2026-001, IOQ-PKG-2026-001 6장 (표준 운전 조건) |
| 합격 기준 | 14항목 (Q-01 ~ Q-14) |
| 시험 규모 | 3배치 × 500컵 이상 |
| 배치 설계 | 배치1 기준 성능 / 배치2 작업자 변동 재현성 / 배치3 세척 후 조건 복원성 |

## 판정 원칙

- PQ 합격 = 3배치 전량 합격 + 합계 기준 충족 + 배치간 재현성(편차 0.3%p 이내)
- 불합격 시 **3배치를 처음부터 재실시** — 불합격 배치만 재실시하는 방식은 인정하지 않음
- PQ에서는 조건을 조정하지 않는다. 조정이 필요하면 OQ로 되돌아가 표준 조건을 재확립한다.

## 수정 방법

```bash
node gen.js && node md.js
```
